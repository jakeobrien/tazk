# Description

Spec docs/tui-spec.md §10.

- Plain wrapped grid: as many 32-col cells per row as fit, left→right then top→bottom; no grouping, no filters.
- Sorted by filename ascending (oldest first).
- Cell 32×7, neutral border: top border = readable creation time or filename; bottom border = filename, dim; body = 2-line preview. Selected cell uses the thick/double border like issue cells.
- Arrow/`hjkl` navigation through the wrapped grid (up/down move by a row, clamped); `PgUp/PgDn/Home/End` sensible equivalents; vertical scroll follows selection.
- Search (§7) applies; selection-disappears rule adapted (same index or last; nothing → 'No matching triage items').
- Selection stored by filename.

# Acceptance Criteria

- State tests: wrapped navigation at widths giving 1, 3 and 5 cells per row; vertical scroll keeps selection visible; search narrows and selection falls back correctly.
- Snapshot tests: triage grid with standard and non-standard names, selected cell, empty-search result.
