# Description

Remove the configurable prefix (tz-39 §6 prefix items, §9 `issue-prefix`, §10 `get_next_number`). Every new ID starts with one constant, `tz-`.

# Design

- Add one constant (e.g. `ID_PREFIX: &str = "tz-"`, or `"tz"` plus the separator, whichever reads best) and use it everywhere an ID is built. Nothing else spells out the prefix.
- Remove: `tz init --prefix`; `Storage::init`'s prefix parameter; `get_prefix`, `infer_prefix`, `infer_prefix_from_issues_dir` and the `issue-prefix` handling in `Storage::open`/`set_config_value`/`write_initial_config`; `tz rename-prefix` and `Storage::rename_prefix`; the `prefix` parameter in `src/hash.rs`.
- `get_next_number`: highest numeric suffix + 1, with no prefix filter.
- `migrate --to hash`, `--to numeric` and `--repack-contiguous`: drop the prefix comparisons and the "different prefix" branch. Leave the gap heuristic for now; tz-44 deletes it.
- If config.yaml contains `issue-prefix`, opening fails with the §9 message, and `tz config set issue-prefix` is rejected. Remove `issue-prefix` from this repo's `.tazk/config.yaml` in the same commit.
- Tests: drop `--prefix …` everywhere (shell tests, `regressions.rs`, storage unit tests, `src/bin/test_tazk.rs`, `random_tazk.rs`) and update expected IDs to `tz-…`. Delete the tests for prefix inference and `rename-prefix`. Much of this is a mechanical search and replace.
- Docs: USAGE (`tz init` flags, the `id` row in the field table), README (config.yaml comment), quickstart text and `--help` strings in `src/main.rs`.

# Acceptance Criteria

- `rg -n 'issue-prefix|get_prefix|rename_prefix|RenamePrefix|infer_prefix' src tests` finds only the §9 rejection and its tests.
- `tz init` (any directory name) followed by `tz create` produces `tz-1`; in hash mode, `tz-<hash>`.
- A config.yaml with `issue-prefix` fails to open with the §9 message; `tz config set issue-prefix x` fails.
- `tz rename-prefix` and `tz init --prefix` are unknown to clap.
- This repo's tracker still works (`tz list`, `tz ready`).
- Docs and help text no longer describe a configurable prefix.
- `make validate` passes.
