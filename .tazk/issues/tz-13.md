# Description

Spec docs/tui-spec.md §2.1. Flags set the initial state only; nothing is persisted.

- `--mode issues|triage` (default issues), `--group-by epic|status|role|type|priority` (default epic).
- `-r/--role`, `-s/--status`, `-t/--type`, `-p/--priority`, `--effort`: repeatable and/or comma-separated, like `tz list -p 0,1`. Literal `none` selects unset role/effort.
- Default status filter = all except `closed` when `-s` is not given.
- `--search TEXT` sets the issues-mode query.
- Invalid values exit with a clear error before the terminal is touched.

# Acceptance Criteria

- Unit tests for parsing: `-p 0,1 -p 3` → {0,1,3}; `-r none,agent` → {(none), agent}; `--effort none` → only unset; invalid `-s foo` and `--group-by bar` produce errors naming the bad value.
- `tz tui --mode triage` starts in triage mode; `tz tui --group-by status -s closed` starts grouped by status showing only closed issues (state-level test).
- `tz tui --help` documents each flag including `none` and the comma/repeat syntax.
