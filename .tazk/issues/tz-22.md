# Description

Spec docs/tui-spec.md §6.1.

- `r`/`s`/`t`/`p`/`e` open one shared multi-select popup for role/status/type/priority/effort, centered over the grid, titled with the property name, footer `space · a/n · ⏎`.
- Rows `[x] value` / `[ ] value`; values from the filter model (incl. `(none)` for role/effort and extra priority values from data).
- `↑/↓`/`j`/`k` move, `Space` toggles, `a` all, `n` none, `Enter` applies, `Esc` cancels and discards edits. Applying an empty selection is allowed (shows no issues).
- Applying triggers column recompute + selection-disappears rule.

# Acceptance Criteria

- State tests: toggle + Esc leaves filters unchanged; toggle + Enter applies; `a`/`n`; empty apply → no visible issues and 'No matching issues'.
- Snapshot test of the status picker over the grid matching the spec mock-up layout.
- Picker keys are inactive in triage mode.
