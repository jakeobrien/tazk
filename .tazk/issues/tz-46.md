# Description

Commands that rewrite IDs (`rename`, `migrate --to hash|numeric`, `--repack-contiguous`, and `renumber` from tz-47) update references in issues and comments but not in triage items. Triage items often name the issue they were found during, so those mentions go stale (tz-39 §7).

# Design

In `Storage::apply_id_mapping` (src/storage.rs), also rewrite ID mentions in every triage item with `replace_issue_ids_in_text`, in the same transaction as the issue and comment writes. Only items whose text changes are written, and their file names (and so creation timestamps) are kept.

# Acceptance Criteria

- Test: a triage item mentioning an issue ID has the mention updated after `rename` and after `migrate --to hash`; an item with no mentions is not rewritten (content byte-identical).
- A dry run lists the triage files it would change.
- A failure part-way leaves issues, comments and triage items all unchanged (covered by the existing transaction tests, extended to a triage write).
- `make validate` passes.
