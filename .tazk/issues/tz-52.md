# Description

Implements spec tz-51: each issue type gets a rule for each of the four standard body sections (optional, required or forbidden), enforced as a hard error on `create`, `triage promote` and `update`. Existing issues that break the rule still load. The unused `--tz-validation` flag is removed.

Children run in `blocked_by` order; the `--tz-validation` removal is independent of the rest.
