# Description

One-time migration of this repo's own tracker from `tazk-N` to `tz-N` (tz-39 §11). It has to land before the prefix is removed (tz-43), so it uses the current binary's `tz rename-prefix`.

Note for the builder: this ticket's own ID changes during the session (its number stays, the prefix becomes `tz-`). Close it and start the commit message with the new ID.

# Design

`tz rename-prefix tz --dry-run`, review it, then run it for real. It renames files and rewrites dependency keys, parents, and ID mentions in issue text and comments. It does not touch triage items, so check `.tazk/triage/` by hand for `tazk-N` mentions and fix any with `tz triage edit`. Leave `.tazk/command_history.log` and Rust test fixtures that happen to use `tazk-N` strings unchanged.

# Acceptance Criteria

- `tz list` shows only `tz-N` IDs, with the same numbers as before.
- `.tazk/config.yaml` has `issue-prefix: tz`.
- `rg '\btazk-[0-9]+\b' .tazk/issues .tazk/triage` finds nothing.
- `tz dep list`/`tz show` on a few issues with dependencies and parents (e.g. the TUI epics and their children) show `tz-N` targets that resolve.
- Committed on its own as `<new-id> Migrate issue IDs tazk-N -> tz-N`.
