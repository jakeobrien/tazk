# Description

Spec docs/tui-spec.md §8.

- Width ≥ 160: split 50/50, grid left, detail right; detail live-follows selection; focus starts on grid; `Enter` focuses detail; `Esc` (empty stack) returns focus to grid; `Ctrl-U`/`Ctrl-D` in grid scroll the detail half a page without moving focus; focused pane has a highlighted border.
- Width < 160: grid only; `Enter` opens full-screen detail; `Esc` (empty stack) returns to grid.
- Resize across the threshold keeps the selection. Full-screen detail → wide: split with detail focused. Split with detail focused → narrow: full-screen detail. Grid focused → narrow: grid only.
- Grid column count/scroll in split mode uses the left half's width.

# Acceptance Criteria

- State tests for every transition in §8 (both resize directions × focus states, Enter/Esc in each layout).
- Snapshot tests: split view at 200×50 with grid focused and with detail focused; full-screen detail at 120×40; grid-only at 120×40.
- Ctrl-U/D in grid only act in split view (keymap predicate).
