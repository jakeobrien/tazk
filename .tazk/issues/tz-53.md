# Description

Implements tz-51 §7.

The global `--tz-validation MODE` flag is parsed in `src/main.rs` (around lines 94-125: the `tz_validation` field on the CLI struct, the `ValidationMode` enum and its `FromStr`), but nothing reads its value. It is documented in USAGE.md under "Options" and shows up in every command's `--help`. Closed ticket tz-44 mentions it, but no tests pass it.

Delete it. Backwards compatibility is not needed (there are no stores outside this repo), so passing the flag should simply become clap's unknown-argument error. How invalid issue files are reported today must not change.

# Acceptance Criteria

- The global `--tz-validation` flag, the `tz_validation` field and the `ValidationMode` enum (with its `FromStr`) are removed from `src/main.rs`, and the flag line is removed from USAGE.md (Options).
- `tz --tz-validation warn list` fails as an unknown argument; a test in a `tests/*.sh` script covers this.
- `make validate` passes.
