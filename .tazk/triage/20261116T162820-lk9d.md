Code review: average lead time is truncated to whole hours

Where: src/storage.rs get_stats (~line 1947): lead_times.push(duration.num_hours() as f64).

Problem: each issue's lead time is truncated to whole hours before averaging, so issues closed within an hour count as 0 and the average is biased low, although the output prints one decimal place.

Suggested fix: use duration.num_seconds() as f64 / 3600.0.
