Code review: ensure_contained does not reject `..` components

Where: src/paths.rs ensure_contained.

Problem: the first check is lexical (path.starts_with(root)), which passes for root/sub/../../x. The loop then canonicalizes the nearest existing ancestor; if root/sub does not exist yet, that ancestor resolves to root and the check passes, while create_dir_all + write would land outside root. Current callers already validate IDs and names (IssueId, PortableName, validate_relative), so this is defense in depth only.

Suggested fix: reject any Component::ParentDir (and non-Normal components after root) in ensure_contained.
