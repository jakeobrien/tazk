Code review: the ID-replacement regex is rebuilt for every text field

Where: src/storage.rs replace_issue_ids_in_text, called from remap_issue for five fields per issue, for every comment body, and for every triage item.

Problem: a regex alternation over all mapping keys is compiled on every call (the code comment acknowledges this). For a full migration that is O(issues x fields) regex compilations over a pattern with one alternative per issue. A compile failure also silently returns the text unchanged.

Suggested fix: compile once per mapping (e.g. a small IdRewriter struct built in apply_id_mapping) and propagate compile errors.
