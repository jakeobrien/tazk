Code review: test-only crates are regular dependencies of tz

Where: Cargo.toml [dependencies]: tokio (rt-multi-thread, time) and similar-asserts.

Problem: only src/bin/test_tazk.rs (behind the test-tools feature) uses them, but every build of tz compiles them. The library's pub mod action_generator is likewise test tooling compiled into every build.

Suggested fix: make them optional dependencies enabled by the test-tools feature (test-tools = ["dep:tokio", "dep:similar-asserts"]) and gate action_generator on that feature too.
