Code review: the tz binary recompiles every module instead of using the tazk library

Where: src/main.rs lines 1-15 (mod code_patch; mod format; mod storage; ...) vs src/lib.rs.

Problem: main.rs declares all modules again, so they are compiled twice and the binary's types::Issue is a different type from tazk::types::Issue. This forces workarounds such as #[allow(dead_code)] in paths.rs ("used by the binary crate, which compiles this module separately"). The library also exposes test-only tooling publicly (pub mod action_generator).

Suggested fix: move all non-CLI modules into lib.rs (pub(crate) where appropriate) and have main.rs `use tazk::...`; put action_generator behind the test-tools feature.
